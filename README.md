# Music Pro 🎵

A premium, modern music player interface built with HTML, CSS, and JavaScript. This project replicates the high-end aesthetic of top streaming services, featuring a "Cyber-Glass" design style with neon accents and glassmorphism effects.

## ✨ Features

*   **Stunning UI/UX:** A unique "Cyber-Glass" design language with deep purple gradients, floating glass panels, and neon glows.
*   **Spotify Integration:** Seamlessly embeds Spotify playlists for actual music playback.
*   **Navigation:** Functional sidebar navigation switching between Home, Search, and Library views.
*   **Dynamic Greetings:** personalized greeting based on the time of day (Good Morning/Afternoon/Evening).
*   **Interactive Elements:**
    *   Hover effects on cards and buttons.
    *   Custom scrollbars.
    *   Detailed profile dropdown menu.
    *   Interactive genre cards in the Search view.
*   **Responsive Layout:** Flexbox and Grid-based layout for a modern web experience.

## 🚀 How to Run

Simply open the `index.html` file in any modern web browser. No rigorous build steps or servers required!

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure.
*   **CSS3:** Advanced styling with CSS Variables, Flexbox, Grid, Animations, and Backdrop Filter (Glassmorphism).
*   **JavaScript (Vanilla):** Logic for navigation, time-based greetings, and playlist switching.
*   **Spotify Embed API:** Core music playback functionality.
*   **Google Fonts:** Using 'Outfit' for modern typography.
*   **Material Icons:** For consistent iconography.
